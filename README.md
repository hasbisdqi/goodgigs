# GoodGigs

GoodGigs is a modern, responsive freelance gig marketplace built on the TALL stack equivalent using Laravel, React, Inertia, and Tailwind CSS. It allows users to browse jobs, apply for gigs, chat with employers, and track live job progress.

## Features

- **Role-based Authentication**: Distinct experiences for Workers, Employers, and Admins.
- **Job Marketplace**: Employers can post gigs; Workers can browse, apply, and accept jobs.
- **Messaging System**: Real-time communication between Employers and Workers.
- **Live Job Tracking**: Track active gigs with status sliders and live maps.
- **Admin Dashboard**: Manage users and review KYC applications securely.

## Requirements

- PHP 8.4
- Node.js & npm (v22+)
- Composer
- A local database (SQLite/MySQL/PostgreSQL)
- Laravel Herd (recommended for Mac) or Laravel Sail/Valet

## Setup & Installation

1. Clone the repository and install dependencies:
   ```bash
   composer install
   npm install
   ```

2. Copy the `.env.example` file to `.env` and generate the app key:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

3. Configure your `.env` for your local database. (If using SQLite, simply create an empty `database/database.sqlite` file and set `DB_CONNECTION=sqlite`).

4. Run migrations and seed the database to get prototype users:
   ```bash
   php artisan migrate --seed
   ```

5. Build frontend assets:
   ```bash
   npm run build
   # Or run the dev server: npm run dev
   ```
